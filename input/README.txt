This is a README file for the Data subfolder in the Ssd1 RNA-binding mechanism paper shared folder.

Data contains 3 subfolders:

1) RTqPCR_Ct
2) Flow_metadata
3) FCS

1) RTqPCR_Ct contains the RT-qPCR Ct values used to generate "2026-03-05_SUN4wholeUTRs_RTqPCR_BK06" (wholeUTRs_Ct), and "2026-03-05_SUN4_5UTRmut_RTqPCR_BK11" (5UTRmuts_Ct), as well as the flow cytometry-RT-qPCR dotplots (BK07, BK13).

2) Flow_metadata contains the metadata excel files loaded into "2026-05-12_SUN4_UTR_flow" and "2026-05-11_Ssd1_pointmutant_flow", for analysis of flow cytometry data

3) FCS contains the .fcs flow cytometry output files loaded into "2026-05-12_SUN4_UTR_flow" and "2026-05-11_Ssd1_pointmutant_flow"
