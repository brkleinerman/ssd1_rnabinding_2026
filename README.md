# ssd1_rnabinding_2026
Analysis of regulation of Sun4 protein abundance by RNA-binding protein Ssd1

# Contents (folders)
* Rmd - flow cytometry and RT-qPCR analysis .Rmd scripts, with .html outputs
* Input - raw data
  + FCS - .fcs flow cytometry files
    + SUN4_UTR_flow - Ssd1-dependent effects on Sun4-mNeonGreen abundance
    + Ssd1_pointmutants_flow - Ssd1 RNA-binding point mutant effects
  + Flow_metadata - excel sheets with strain information to analyze .fcs files
  + RTqPCR_Ct - RT-qPCR Ct (Cq) values
    + 5UTRmuts_Ct - from strains with mutant 5' UTRs
    + wholeUTRs_Ct - from strains with swapped UTRs
  + RTqPCR_coeff - .tsv files with mean deltadeltaCq values for each strain
  
See README files in Rmd and input folders for more detailed explanations of contents
