This is a README file for the Scripts subfolder in the Ssd1 RNA-binding mechanism paper shared folder.

The script 2026-05-12_SUN4_UTR_flow uses .fcs files in "SUN4_UTR_flow" (see Data > FCS), to make plots "2026-03-05_SUN4wholeUTRs_flow_BK05", "2026-03-06_SUN4wholeUTRs_flow_RTqPCR_cor_BK07", "2026-03-05_SUN45UTRmuts_flow_BK10", and "2026-03-06_SUN45UTRmuts_flow_RTqPCR_cor_BK13".

2026-05-11_Ssd1_pointmutant_flow uses .fcs files in "Ssd1_pointmutants_flow" (see Data > FCS) to make "2026-03-05_Ssd1_pointmutant_flow_BK12".

2026-05-12_SUN4wholeUTRs_RTqPCR uses Ct values in "wholeUTRs_Ct" (see Data > RTqPCR_Ct) to make "2026-03-05_SUN4wholeUTRs_RTqPCR_BK06" and "2026-03-06_SUN4wholeUTRs_flow_RTqPCR_cor_BK07" 

2026-05-12_SUN4_5UTRmuts_RTqPCR uses Ct values in "5UTRmuts_Ct" (see Data > RTqPCR_Ct) to make "2026-03-05_SUN4_5UTRmut_RTqPCR_BK11" and "2026-03-06_SUN45UTRmuts_flow_RTqPCR_cor_BK13".



Note: Linear model coefficients of deltadeltaCq values are calculated first in 2026-05-12_SUN4wholeUTRs_RTqPCR and 2026-05-12_SUN4_5UTRmuts_RTqPCR, then plotted against log10 linear model coefficients of SUN4-mNeonGreen/FSC_A means in 2026-05-12_SUN4_UTR_flow, to generate "2026-03-06_SUN4wholeUTRs_flow_RTqPCR_cor_BK07" and "2026-03-06_SUN45UTRmuts_flow_RTqPCR_cor_BK13".
